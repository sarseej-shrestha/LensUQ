# Terminology

| Term | Meaning |
| --- | --- |
| Pipeline space | User-declared finite Cartesian alternatives in ordered preprocessing stages. |
| Factor | One preprocessing stage with alternative levels. |
| Level | One labeled transformer or passthrough option. |
| Universe | One concrete factor combination with its independently fitted model. |
| Nominal universe | First executed universe; a reference, not a selected winner. |
| Prediction sensitivity | Variation in predictions across executed universes for one observation. |
| Decision agreement | Largest class vote count divided by executed universe count. |
| Main effect | One factor's orthogonal sum-of-squares component on a complete product. |
| Pairwise interaction | Two-factor component after their main effects are removed. |
| Residual | Higher-order variation remaining after main and pairwise components. |

See [[Choice and Pipeline Space]], [[Classification Analysis]], [[Regression Analysis]], and [[Attribution Model]].
