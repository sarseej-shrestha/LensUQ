## Research-dependent work

- Constrained choices: define the target measure before implementing enumeration.
- Weighted spaces: choose and document a nonorthogonal attribution convention.
- Interaction detail: add validated pairwise/higher-order decomposition rather than renaming the residual.
- Continuous choices: specify measures and convergence diagnostics.
- Repeated seeds and data resamples: preserve replication axes rather than flattening them into universes.

## Lessons from 0.1

Complementary vote fractions can differ in floating-point arithmetic when one is derived by subtraction. Integer-derived agreement fixes ranking symmetry. In-place transformers require input isolation as well as estimator cloning. Exact constants should be centered by differences to avoid spurious nonzero attribution.
